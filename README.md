# Hydroponic Environment Classification Using Scikit-learn

## Project Overview

This project develops a machine learning-based classification
system to evaluate environmental suitability for hydroponic
cultivation.

The system uses temperature, water pH, and season as input
parameters and provides environmental suitability results
along with plant recommendations.

## Tech Stack

- Python
- Scikit-learn
- Tkinter
- Machine Learning
- Classification

## Features

- Environmental suitability classification
- Temperature and water pH input
- Season selection
- Plant recommendations
- Interactive graphical user interface

## How It Works

1. User inputs temperature, water pH, and season.
2. The classification model processes the input.
3. The system determines environmental suitability.
4. The system recommends suitable plants.
